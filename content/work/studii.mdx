Studii is a cloud-native SAT-prep platform that delivers real-time, adaptive
quizzes at scale, with AI-generated questions and personalized tutoring.

- Ingested and normalized the official College Board SAT question bank into a
  structured PostgreSQL schema (via Supabase), tagging every item by subject,
  skill, and difficulty across Reading and Math domains — the backbone for
  adaptive practice.
- Engineered a cloud-native microservice architecture (Next.js, React, GraphQL,
  PostgreSQL, Docker on AWS ECS) delivering secure, real-time quizzes to 1,000+
  students, with scalable CI/CD via GitHub Actions.
- Powered 10,000+ quiz sessions on containerized services, and integrated
  OpenAI APIs for dynamic question and answer generation, enabling personalized
  tutoring at scale.
